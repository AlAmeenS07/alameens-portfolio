## 🌟 Features & Highlights

- **Modern & Premium Design System**: Crafted with custom HSL color palettes, subtle earth-tone aesthetics, sleek typography (Plus Jakarta Sans & Inter), and micro-animations.
- **Hero & About Section**: Highlighting technical specialties, key philosophy, direct resume download, and social link cards.
- **Skills Infinite Marquee**: Dynamic dual-track infinite marquee displaying core technologies, tools, and architecture principles.
- **Career & Learning Journey**: Interactive horizontal timeline showcasing education, intense Brototype MERN training, and enterprise freelance experience.
- **Life & Achievements Showcase**: Highlighted awards and leadership roles:
  - **Overall Best Performer** (BroCamp)
  - **Team Lead of Project**
  - **ACE Student Lead** (BroCamp Advanced Curriculum for Excellence)
  - **ACE Community Program Coordinator**
- **Photo Showcase Gallery**: Visual grid featuring key milestone moments and achievements.
- **Fully Responsive**: Optimized fluid typography and layout for Desktop, Tablet, and Mobile devices (including uniform touch-friendly link cards on mobile).
- **SEO & Performance Best Practices**: Semantic HTML5, canonical links, Open Graph & Twitter meta tags, fast asset delivery, and accessibility compliance.
- **Direct Engagement**: Integrated WhatsApp quick-message shortcut and copy-friendly email connection.

## 🚀 Local Development Setup

To run this project locally, simply clone the repository and open `index.html` in your preferred web browser, or serve it using any local static file server.

```bash
# Clone the repository
git clone https://github.com/AlAmeenS07/Portfolio.git

# Navigate to the project directory
cd Portfolio

# Open using VS Code Live Server or any HTTP server
npx serve .
```
